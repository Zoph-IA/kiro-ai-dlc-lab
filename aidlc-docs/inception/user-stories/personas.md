# Flappy Kiro — Player Personas

## Persona: Alex the Casual Gamer

| Attribute | Description |
|---|---|
| **Name** | Alex |
| **Type** | Casual Desktop Gamer |
| **Age Range** | 18–35 |
| **Technical Skill** | Comfortable with web browsers, familiar with keyboard controls |
| **Gaming Experience** | Plays browser games during breaks, familiar with Flappy Bird mechanics |
| **Motivation** | Quick entertainment, beat personal high score, satisfying gameplay loop |
| **Frustration Points** | Unfair difficulty spikes, unresponsive controls, unclear game state |
| **Goals** | Easy to start playing, clear feedback, smooth controls, track progress |
| **Context** | Playing on a desktop browser during a break, wants instant engagement |

### Key Characteristics
- Expects the game to be immediately playable without instructions
- Wants responsive, predictable controls
- Motivated by beating their own high score
- Appreciates clean visuals that don't distract from gameplay
- Wants sound feedback but also the option to mute
- Expects a quick restart loop after dying
